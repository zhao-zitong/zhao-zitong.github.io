# Zitong Zhao Academic Website

This repository contains the static files for Zitong Zhao's personal academic website.

## Local Preview

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Publishing

The Git remote is:

```text
https://github.com/zhao-zitong/zhao-zitong.github.io.git
```

Because this is a `zhao-zitong.github.io` repository, GitHub Pages publishes the site from the `main` branch at:

```text
https://zhao-zitong.github.io/
```

Push committed changes to `main` to publish updates.
